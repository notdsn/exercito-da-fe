Como jogar
  • Compre heróis e criaturas na loja com elixir. Arraste do banco para o seu lado do tabuleiro.
  • 3 cópias iguais se fundem em uma unidade ★★ (e 3 ★★ viram ★★★).
  • Junte 2 ou 4 unidades do mesmo traço para ativar sinergias (ícones à esquerda — toque para ver o bônus).
  • Aperte Lutar! (ou espaço): o combate é automático. Mana cheia = habilidade especial!
  • Arraste uma unidade para a loja para vender. D renova a loja.
  • Derrote todos os rivais para vencer. Se sua vida chegar a 0, fim de jogo.
